> 画像のアップロード不要！完全ローカルで動作するカラーピッカー＆色彩感覚トレーニングアプリを紹介します。

## はじめに

二次創作などでキャラクターを描く際、 **「公式と同じ色を自力で再現するのが難しい…」** と悩んだことはありませんか？

Clip Studio Paintなどのペイントソフトにもスポイト機能はありますが、いちいちキャンバス内にリファレンス画像を読み込まなければ使えず、少し手間がかかります。かといって、便利なWeb上のカラーピッカーツールを使おうにも、著作権の観点から版権画像を外部サーバーにアップロードするのは避けたいところです。

そこで、 **「動作が軽快」** かつ **「画像のアップロード不要（完全ローカル）」** でありながら、 **「ゲーム感覚で色彩感覚まで鍛えられる」** という理想をすべて満たすWebアプリ **「ColorSensei」** を作成しました！

> ※算出される色空間の値（CMYK, L*a*b*等）は標準的な計算式による近似値であり、Clip Studio等のペイントソフトとは微小な誤差が生じる場合があります。

まずは、完成したアプリを直接触ってみてください。

## 概要と使い方（機能デモ）

**ColorSensei** は大きく分けて2つのモードを搭載しています。

### 1. カラーピッカーモード

![カラーピッカーモードのスクリーンショット](/images/colorsensei-picker.png)

画像を画面にドラッグ＆ドロップするだけで、即座に画像の読み込みが完了し、画像の好きな場所から色を抽出（スポイト）できます。ルーペ機能も備えているため、ピクセル単位での正確な色抽出が可能です。

抽出した色は、 `HEX / RGB / CMYK / HSV / HSL / L*a*b*` の6種の色空間に自動で変換・表示されます。
さらに、各数値には **コピーボタン** が付いており、ワンクリックでクリップボードにコピー可能です。コピーした数値をそのままClip StudioやPhotoshopなどのペイントソフトに貼り付ければ、全く同じ色を即座に再現できます。

**二次創作でキャラクターの色を忠実に再現したいときに非常に便利な機能です！**

### 2. 色彩感覚クイズモード

単に色を取るだけではなく、自分の「目」を鍛えるためのクイズモードです。

![クイズモードのスクリーンショット](/images/colorsensei-quiz.png)

クイズには2つの出題方法があります。
* **モードA（ランダム）** : 画像上のランダムな位置の色が出題されます。
* **モードB（指定）** : 自分で画像上の好きな場所をクリックして、ターゲット色を設定できます。

ターゲット色が提示されたら、隣にあるカラーピッカーを操作して、 **できるだけターゲットに近い色を自力で作って回答** します。
回答すると、正解の色との差分が「ΔE（色差）」という指標に基づいて計算され、100点満点で厳密にスコアリングされます。

回答数・平均スコア・最高スコアの統計も表示されるため、スコア更新を目指しながら **ゲーム感覚で色彩感覚（自分の目で色を捉え、再現する能力）を鍛える** ことができます。

## 使用した技術

### 1. File APIによる完全ローカル処理

画像の読み込みには、JavaScriptの `URL.createObjectURL()` を活用しています。これにより、ユーザーが選択した画像を外部のサーバーに一切アップロードすることなく、ブラウザのメモリ上だけで直接表示・処理させることが可能です。
通信ラグが発生しないため動作が非常に軽快で、版権画像の読み込みもセキュリティ面で安心です。

### 2. Vanilla JSによる色空間変換とΔEスコアリング

ReactなどのUIフレームワークや外部のnpmパッケージを一切使わず、すべての処理をVanilla JavaScript（素のJS）で記述しています。
以下では、本アプリの中核となる「色空間変換」と「色差によるスコアリング」の仕組みを紹介します。

#### L\*a\*b\* 色空間とは？

普段私たちが目にするRGBやHEXといった色の表現は、あくまで「ディスプレイが色を表示するための仕組み」であり、人間が実際に感じる「色の違い」とは必ずしも一致しません。
たとえばRGB上で同じ数値だけ変化させても、ある色域では大きな違いに見え、別の色域ではほとんど差を感じないことがあります。

そこで登場するのが **L\*a\*b\* 色空間**（CIE 1976 L\*a\*b\*）です。
これは国際照明委員会（CIE）が定めた色空間で、 **「人間の目が感じる色の違いと、数値上の距離が均等に対応する」** ように設計されています。

* **L\*（明度）**: 色の明るさ（0＝黒 ～ 100＝白）
* **a\*（色相）**: 緑（−）～ 赤（＋）方向の軸
* **b\*（色相）**: 青（−）～ 黄（＋）方向の軸

> 💡 L\*a\*b\* 色空間についてより詳しく知りたい方は、[パパラボ様の解説ページ](https://www.papalab.co.jp/colormeter/lab/)がとても分かりやすくおすすめです。

本アプリでは、画像から取得した sRGB 値を、以下の流れで `L*a*b*` に変換しています。

:::details sRGB → L\*a\*b\* 変換の実際のコード（JavaScript）
```javascript
function rgbToLab(r, g, b) {
  // ① sRGB → リニアRGB（ガンマ補正の除去）
  let rl = r / 255, gl = g / 255, bl = b / 255;
  rl = rl > 0.04045 ? Math.pow((rl + 0.055) / 1.055, 2.4) : rl / 12.92;
  gl = gl > 0.04045 ? Math.pow((gl + 0.055) / 1.055, 2.4) : gl / 12.92;
  bl = bl > 0.04045 ? Math.pow((bl + 0.055) / 1.055, 2.4) : bl / 12.92;

  // ② リニアRGB → XYZ色空間（D65光源基準の変換行列）
  let x = rl * 0.4124564 + gl * 0.3575761 + bl * 0.1804375;
  let y = rl * 0.2126729 + gl * 0.7151522 + bl * 0.0721750;
  let z = rl * 0.0193339 + gl * 0.1191920 + bl * 0.9503041;

  // ③ XYZ → L*a*b*（D65基準白色点で正規化）
  const xn = 0.95047, yn = 1.00000, zn = 1.08883;
  x /= xn; y /= yn; z /= zn;

  const epsilon = 0.008856;
  const kappa = 903.3;
  const f = t => t > epsilon ? Math.cbrt(t) : (kappa * t + 16) / 116;

  const fx = f(x), fy = f(y), fz = f(z);
  return {
    l: 116 * fy - 16,   // L*: 明度
    a: 500 * (fx - fy),  // a*: 緑～赤
    b: 200 * (fy - fz)   // b*: 青～黄
  };
}
```
変換は `sRGB → リニアRGB → XYZ → L*a*b*` の3ステップで行われます。各ステップの変換行列や定数はCIEの国際規格に基づいた値です。
:::

#### ΔE76（色差）によるスコアリング

クイズのスコアリングには **「CIE76色差式（ΔE76）」** を使っています。
これは色彩の分野で広く用いられている標準的な色差の計算方法で、印刷・塗料・ディスプレイの品質管理など、産業界でも実際に使われている信頼性の高い指標です。

計算自体はシンプルで、先ほど変換した `L*a*b*` 空間上の2色を「3次元空間上の2つの点」と見なし、その **ユークリッド距離（直線距離）** を求めるだけです。
`L*a*b*` が人間の知覚に合わせて設計されている色空間だからこそ、この単純な距離計算で「人間が感じる色の違い」を正確に数値化できるのです。

さらに、算出された色差（ΔE）をもとに、100点満点のスコアに変換する独自の計算式を組み込みました。小さな誤差には寛容で、ズレが大きくなるほど急激に減点される非線形な計算（1.5乗）を用いることで、ゲームとしての絶妙な難易度調整を行っています。

:::details 実際のスコアリング用コード（JavaScript）
```javascript
// CIE76色差式の計算 (L*a*b*空間におけるユークリッド距離)
function deltaE76(lab1, lab2) {
  return Math.sqrt(
    (lab1.l - lab2.l) ** 2 +
    (lab1.a - lab2.a) ** 2 +
    (lab1.b - lab2.b) ** 2
  );
}

// 色差(ΔE)から100点満点のスコアを計算
// DE_THRESHOLD（閾値=100）を超えたら0点。非線形(1.5乗)で減点する。
function calculateScore(dE) {
  const DE_THRESHOLD = 100;
  if (dE >= DE_THRESHOLD) return 0;
  // 小さな誤差には甘く、大きな誤差には厳しくなる計算式
  return Math.max(0, Math.round(100 * Math.pow(1 - dE / DE_THRESHOLD, 1.5)));
}
```
:::

### 3. 単一ファイル構成によるゼロインストール設計

本アプリは、HTML / CSS / JavaScript のすべてを1つの `index.html` にまとめた **単一ファイル構成** を採用しています。
Node.jsやWebpack、Viteといったビルドツールへの依存を完全に排除した設計判断により、驚異的なポータビリティを実現しました。
リポジトリから `index.html` を手元にダウンロードしてダブルクリックするだけで、 **環境構築なしに即座にローカルで使い始めることが可能** です。もちろん、GitHub Pagesへのデプロイもこのファイル1枚で完結しています。
